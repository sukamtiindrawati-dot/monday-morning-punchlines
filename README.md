`main.py` (Python 3.13, standard library only) scores six original candidate
Monday-morning punchlines against the judge's five criteria — Monday-ness,
punchline, surprise, economy, freshness — and writes the winning one-liner to
`/output/entry.txt`.

Winning line (87 characters):

> Monday introduced itself as Friday's twin. Same face, worse personality, earlier alarm.

Run it locally:

```sh
python3 main.py
```
